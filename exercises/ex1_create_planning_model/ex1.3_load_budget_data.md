# Load budget data
In this exercise, you will add budget data to your model via a data import job. 

1. Download this [Excel file](../files/AM_DA260_BASE_BUD.xlsx) to your computer. 
2. Navigate to Data Management.

![](../images/ex1.3_1.png)

3. Import data
![](../images/ex1.3_2.png)

4. Select the Excel file you just downloaded.
   ![](../images/ex1.3_3.png)

5. Set up the import.
   ![](../images/ex1.3_4.png)

6. Review the issues on the Company Code column and set the column as String.
![](../images/ex1.3_5.png)
![](../images/ex1.3_6.png)

7. Set 'Account' and 'AccountParent' as String. You can do so by clicking on the column header names in the grids.
![](../images/ex1.3_6a.png)
![](../images/ex1.3_6b.png)

8. Click 'Next'.
 ![](../images/ex1.3_7.png)

9. Set 'Public.Budget' as default version.
 ![](../images/ex1.3_8.png)
 ![](../images/ex1.3_9.png)

10. Map 'CompanyCodeDescription', 'ProductDescription', 'ProductGroup', 'ProductHierarchy' as per the image below.
 ![](../images/ex1.3_10.png)

11. Map 'AccountParent'
 ![](../images/ex1.3_13.png)

12. Click 'Next', 'Run Import' and 'Finish'
 ![](../images/ex1.3_11.png)
 ![](../images/ex1.3_12.png)
